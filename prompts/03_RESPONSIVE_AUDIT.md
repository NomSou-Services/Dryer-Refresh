# Grok Prompt — Responsive Audit

Audit the affected page at approximately:

- 320px
- 375px
- 430px
- 768px
- 1024px
- 1440px
- wide desktop

Check:
- horizontal overflow,
- text wrapping,
- navigation,
- grids,
- buttons,
- form controls,
- images,
- sticky/fixed elements,
- spacing,
- touch target usability.

Do not redesign the page.

Fix only responsive defects and explain each meaningful change.
