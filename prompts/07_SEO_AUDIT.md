# Grok Prompt — SEO Audit

Audit public routes for technical SEO.

Check:
- unique titles,
- descriptions,
- canonical URLs,
- crawl/index behavior,
- sitemap coverage,
- robots rules,
- Open Graph data,
- useful internal links,
- semantic heading structure,
- structured data accuracy,
- image alt text,
- route status codes.

Do not generate fake local-business claims, reviews, locations, awards, or credentials.

Fix technical issues and list content decisions that still require human input.
